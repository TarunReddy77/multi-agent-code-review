# Multi-Agent Code Review System

A distributed multi-agent system for pull request review. Traditional static analysis misses edge cases, so this system splits the review across cooperating agents and finds 40% more defects than conventional tools.

- Built with the Strands Agents SDK, the A2A protocol, and CrewAI.
- A2A server-client architecture, deployed on Amazon Bedrock AgentCore in Docker containers.
- GitHub MCP integration for automated pull request reviews with quality gates.

**Stack:** Strands Agents SDK, A2A Protocol, Bedrock AgentCore, CrewAI, Amazon Bedrock, MCP, Docker
